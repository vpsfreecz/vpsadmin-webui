# VPS list controls and resources

VPS-09, VPS-10 and VPS-11, linked to REQ-010. The list reserves a stable
primary slot and exposes the existing restart and shutdown gate reasons.
The table and cards share aligned resource labels. A stopped VPS retains
its allocated RAM and disk. The last runtime load and RAM measurement
are omitted for a stopped or unknown power state.

Terminology checked at a65a4dfeb92a59df4a80a737a20bcbf8558793ff.
Tests use synthetic running and stopped VPS records and exercise mobile
and desktop action positions, disabled controls and resource values.
