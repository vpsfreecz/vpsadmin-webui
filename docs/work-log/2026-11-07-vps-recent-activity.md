# VPS recent activity

ACT-01 from the approved TODO series, linked to REQ-051. The VPS overview
places the operation, time and state in compact rows. The operation wraps
when space is tight. The timestamp follows the interface language and the
account time zone. The activity button opens the VPS-filtered list.

The browser fixture checks a long operation name, the timestamp in a
non-browser time zone, and the scoped activity link. It uses synthetic
records. The transaction API and its permissions are unchanged.
