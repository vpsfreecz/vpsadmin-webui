# Compact VPS detail header

DET-01 and DET-03, linked to REQ-010. The title groups the VPS ID and
status with its identity. Long names wrap without displacing the primary
action. The SSH command and copy action share a surface, and long commands
wrap so narrow screens can display the complete value. The same clipboard
helper provides confirmation.

Tests check a long synthetic hostname, IPv6 SSH, keyboard and touch-sized
controls, and the full copy value. VPS permissions and actions are unchanged.
