# Work-log entries

This directory is the current work log. Keep one English Markdown file per
change here, named `YYYY-MM-DD-short-topic.md`.
Record the request and rationale, implementation, requirement/PR references,
verification scope and outcome, deployment status, and remaining limitations.
Append follow-ups to that change's file. Link to its rationale and results from
affected guidance rather than repeating them. Do not rewrite a shared
current-status entry for concurrent changes or add new summaries to a central
index or the root log.

The existing [root work log](../../WORK_LOG.md) remains historical evidence.
Browse this directory for new entries. A fixture pass is not live API evidence;
a prepared PR is not a merged or deployed change.
