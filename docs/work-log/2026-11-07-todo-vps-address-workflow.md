# VPS address workflow

NET-06, NET-07 and NET-08 follow REQ-050 and
[Discourse #19](https://discourse.vpsfree.cz/t/372/19). The route and host
address cards carry steps one and two, with contextual instructions and
errors in their respective cards. The assigned route shows its interface
beside the address. Host addresses show an existing PTR beside the address,
with the same Add or Edit PTR action for accounts allowed to use it.
